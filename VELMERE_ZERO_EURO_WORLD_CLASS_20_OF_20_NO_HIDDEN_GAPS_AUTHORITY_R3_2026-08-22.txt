7. PROVIDER INDEPENDENCE DAG — NEW R2 CONTROL
======================================================================

Every provider/evidence row gets:

upstream_root_id

Examples:
CVE record → NVD enrichment of same CVE:
same vulnerability root for independence purposes unless the second source
adds independently originated evidence.

GitHub Advisory → OSV record whose source is GitHub Advisory:
same upstream_root_id for that advisory.

DEX Screener price → Velmère TWAP calculated from the same DEX Screener
samples:
same market-data root, although the TWAP is Velmère-derived.

Two RPC providers returning the same public chain block:
different transport providers, same underlying blockchain truth family.
They can prove transport quorum, but must not automatically count as two
independent substantive evidence families.

Anti-inflation rules:
- retries = 0 new slots
- mirrors = 0 new slots
- aliases = 0 new slots
- proxy API over same origin = 0 new slots
- provider rebrand = 0 new slots
- copied advisory = 0 new slots
- same API under two domains = 0 new slots
