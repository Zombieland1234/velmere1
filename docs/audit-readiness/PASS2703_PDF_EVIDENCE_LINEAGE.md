# PASS2703 — Pro PDF Evidence Lineage

Goal: every PDF claim must have source lineage.

## Required sections
1. Cover and scope.
2. Verdict with confidence, not guarantee.
3. Claim-to-source table.
4. Freshness and stale warnings.
5. Missing evidence.
6. Audit Replay Capsule.
7. Receipt/support handoff.

## Blockers
- Bare claim without evidence id.
- Mixed locale.
- Debug markers.
- Raw provider payloads.
